# 可视化Cron生成器（Cron Pulse）

纯前端、零运行时依赖、完全离线的 Cron 表达式工作台。自研统一核心引擎覆盖 Unix、Spring、Quartz 全方言，提供双向编辑、逐字段校验与错误定位、中英可读描述、时区与夏令时感知的执行时间预测、方言互转与多生态代码片段。

## 功能

- **全方言解析**：Unix / Linux crontab（5 位）、Spring `@Scheduled`（6 位）、Quartz（6 位或带年份的 7 位）；另有兼容档位用于粘贴识别与代码片段生成。
- **完整语法**：`*`、`?`、`,`、`-`、`a/b`、`*/b`、月份与星期名称（前 3 字母）、`L`、`L-n`、`LW`、`nW`、`dL`、`d#n`、年份范围与步长、宏、`6~15` 随机区间与 `@reboot` 的专属警告。
- **校验与定位**：一次报出全部错误与警告，每条带字段序号和字符偏移，可点击跳转到对应字段；Quartz 的 `日` / `周` 冲突提供一键修复。
- **可读描述**：中文与英文逐字段展开 + 组合句，显式说明 `日` / `周` 是并集还是交集，以及夏令时带来的影响。
- **执行时间预测**：按天推进候选日 + 天内位图枚举，支持 `skip` / `shift` 两种夏令时缺失时刻策略；重复时刻取较早实例；被跳过的调度点单独列出；5 年扫描窗口熔断。
- **双向构建器**：以 AST 为唯一真源，切换方言时按访问器契约重映射星期编号，并给出可撤销的黄色提示。
- **互转与片段**：三种方言并排对比与差异高亮；输出 Java、Go、Python、JS/TS、K8s、XXL-JOB、POSIX crontab 等生态片段，目标生态不支持时显示警示而不是伪造代码。
- **预设**：底部常用表达式预设 chips 是方言无关的概念，可一键载入；显示与载入都按当前方言自动换算记法，不会改动你选的方言。

## 支持的方言与语法差异

| 方言 | 字段 | 星期编号 | 日 / 周关系 | 年份 |
|---|---|---|---|---|
| Unix (Linux Crontab) | 分 时 日 月 周 | 周日 = `0` 或 `7`，周六 = `6` | 并集（满足任一即触发） | 无 |
| Spring (@Scheduled) | 秒 分 时 日 月 周 | 周日 = `0` 或 `7`，周六 = `6` | 交集 | 无 |
| Quartz (Java) | 秒 分 时 日 月 周 [年] | 周日 = `1`，周六 = `7` | 交集，且应恰有一个为 `?` | 可选第 7 位 |

`5L` 在 Spring 与 `6L` 在 Quartz 都表示「本月最后一个星期五」：同一数字在两种方言下含义不同，界面用常驻红字提示与警告条明确标出。

## 使用方式

1. 在 DBX 中从应用工具栏或命令面板打开「可视化Cron生成器」。
2. 在顶部输入表达式并选择方言、时区、预览条数与夏令时策略。
3. 校验状态条显示绿 / 黄 / 红；点击错误项可定位到字段卡。
4. 右栏三个页签分别查看描述、执行时间线（含 canvas 时间轴）与代码片段。
5. 底部常用预设可一键载入表达式。

界面语言与主题跟随宿主，描述语言可手动在中文 / 英文之间切换对照。

## 数据与权限

- 仅声明 `host.storage` 权限，用于保存用户偏好（方言、时区、预览条数与夏令时缺失时刻策略）。宿主不提供该能力时自动降级为本次会话内存态。
- 不联网、不发起网络请求、不读取数据库或连接、不执行外部命令；剪贴板仅在用户点击「复制」按钮时写入表达式文本，不读取剪贴板内容。
- 不调用弹窗类原生 API，所有提示由界面内自绘组件呈现。
- 所有时间计算只使用运行时内置的 `Intl.DateTimeFormat`，无第三方运行时依赖。

## 本地开发

```bash
npm ci
node --test
python _domcheck.py
npm i -g @dbx-app/plugin-cli@0.1.9
dbx-plugin package . --target universal --output-dir dist
node _verify.mjs "dist/*.dbxp"
dbx-plugin dev --port 5190
```

发行包只包含 `assets/` 与 `ui/`；测试、开发脚本、依赖清单与本机文档均不进入包。`package.json` 中的依赖只用于差分测试。
